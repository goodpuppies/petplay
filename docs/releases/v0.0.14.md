# PetPlay v0.0.14

Lighter on the GPU and CPU when running beside a game, with steadier menus and faster VRChat
camera calibration.

- Eye render targets now follow the headset's recommended size instead of always using 3560 px
  per eye. A Quest 3 over Steam Link drew about 2.8x the pixels it asked for.
  `--webxr-raylib-eye-size` still overrides this.
- A slow compositor is no longer mistaken for SteamVR standby. Over Steam Link, a game at about
  30 fps caused repeated false stalls of 100 ms each. PetPlay also no longer spins a CPU core
  while waiting on a late compositor.
- Wrist menu readouts no longer flash each time their value changes.
- Recenter brings back a lost or deleted keyboard under the primary display, and stands a
  tipped-over primary display back up.
- VRChat camera calibration accepts more natural hand speeds and collects about twice as many
  samples, shows a first fit sooner, and starts over by itself when VRChat changes worlds.
- A restarting webxr worker no longer exits the whole server.

The camera integration remains experimental. Desktop builds are produced by release CI for
Windows x64 and Linux x64, with an experimental Linux ARM64 build. Real Steam Frame validation
remains incomplete.
