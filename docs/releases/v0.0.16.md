# PetPlay v0.0.16

Multiple monitors on Windows, and a way back after deleting every window.

- Windows now captures all of your monitors, with one PetPlay display per monitor and the primary
  monitor on the first display. Connecting or removing a monitor needs a PetPlay restart.
- The mouse now reaches every monitor on Windows. In v0.0.15 it could land on a different monitor
  from the one shown in the headset.
- Recenter rebuilds the starting layout when every display has been deleted. Before, a layout with
  no displays stayed empty until its saved file was removed.
