# PetPlay v0.0.15

Fixes desktop displays on Windows.

- Displays now appear on Windows. PetPlay could only assign a monitor to a display through KDE, so
  on Windows every display stayed unassigned and its screen never reached the headset. Windows now
  uses its captured desktop as the display's monitor, and layouts already saved without a monitor
  pick it up automatically.

Multi-monitor Windows setups still show a single monitor.
