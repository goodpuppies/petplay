# Roboto Regular

Font data copyright Google 2014. Licensed under Apache-2.0; see LICENSE.txt.

Static Roboto Regular, version 2.000980 (2014), copied from the locally installed Roboto family
(`~/.local/share/fonts/windows/system/Roboto-Regular.ttf`). Used for vector outlines by the
experimental Pathfinder text backend. Existing BMFont layout continues to supply glyph positions.
This font file's version may differ from the font used to generate the old MSDF atlas; exact
outline equivalence with that atlas has not been established.
